# Contributing

Issues and pull requests are welcome. Run `node test/run.js` and
`python3 verify.py libs` first; both are dependency free.

One condition, which is the only reason this file exists: by opening a pull
request you license what you wrote to Federico Mastellone under the
repository's terms, and you grant the right to relicense it, including
commercially. You keep your copyright in it. Without that grant a single merged
patch would leave the project unlicensable to anyone, because every contributor
would have to be found and asked first.
